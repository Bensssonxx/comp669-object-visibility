# 项目方向与贡献边界

主题：区分主体可见性与遮挡位置对视觉模型鲁棒性的影响。

研究问题：相同图像可见面积下，保留下来的主体面积是否不同？在主体可见程度接近时，不同位置与模式的表现差异是否仍然存在？AIMv2 和 DINOv2 在这些条件下的行为是否不同？

第一轮用 Oxford-IIIT Pet 的品种分类及像素级前景标注，替代原 proposal 的 ImageNet-100。原因是需要测量主体可见性。结果必须明确写成该数据集上的 pilot，不能冒充 ImageNet 实验。

计划贡献是：(1) 记录并展示主体可见程度的可复现评估流程；(2) 对冻结 AIMv2/DINOv2 的系统行为分析；(3) 在同图、同遮挡面积与形状下，构建主体可见性差异大／接近的诊断样本对，并明确不能解释的因素。

已有 PatchDrop 工作研究过前景、背景与随机遮挡。因此这里是复现与扩展，不能声称首次区分主体和背景。细化空间位置比较、使用像素标注量化可见性、在当前冻结模型上检查结论，是本课程项目的具体工作；是否具有论文级新颖性尚未建立。

主体面积不是语义信息量。可见同样多的像素可能保留了眼睛，也可能只保留了毛发；这仍是解释限制。跨模型差异只能描述行为，不能归因于 prefix attention。像素填充保留所有 token，不代表节省推理计算。

Milestone 必须展示实际输入、初步结果与分析、后续计划、代码链接和 AI 使用说明。真实负结果可接受。完整训练/验证/测试划分、数据与模型来源、运行配置、失败样本和不确定性均需保留。
