# Moving visible patches while matching animal area

November 10, 2026. The earlier results and the poor overlap of existing uniform-random masks motivated this additional experiment. Both image cohorts have already appeared in this project. The following design precedes predictions on the new masks.

Use the existing 740 main images and 185 annotated images as separate cohorts. Show 64 of 256 patches (25% of the image) with gray fill. Start with the original center mask. Group the 256 patches into ten bands according to the fraction of foreground pixels in each patch. Within each band, sample the same number of patches as the center mask selected from that band. This creates a mask that uses the annotation and has a different distribution from uniform random masking.

For each of two predetermined seeds, accept the first sample that moves at least 16 of the 64 visible patches, has animal visibility within three percentage points of center, and differs from the other sample. Try up to 32 times per seed and include an image only if both seeds succeed. Save all eligible and excluded image IDs before prediction. Record actual coverage, exchanged patches, and shared mask bytes. Image, model, classifier, fill and visible pixel count stay fixed. Specific parts, background pixels, patch adjacency and distances can all change.

Predict the center image and both relocated versions with the original frozen encoders and probes. Verify the center predictions against the prior experiment. Average the two relocated outcomes per image. Report original and eligible counts and point estimates for each cohort. For inference, compute the two within-model changes (center minus relocated) and their difference. Use a paired 10,000-draw bootstrap of images within represented breeds. Report pointwise and approximate simultaneous intervals for these three comparisons within each cohort. Inference is conditional on the eligible images and the two fixed seeds. This diagnostic does not quantify how much of the uniform-random comparison can be attributed to a single cause.
