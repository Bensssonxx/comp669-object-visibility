# Follow-up comparisons for the final presentation

November 10, 2026. This is an exploratory reanalysis of existing predictions. The original main results and their analysis protocol are already known. The rules below were written before computing the two follow-up tables.

1. On each original image, subtract masked correctness from clean correctness separately for each model. Positive values indicate a loss. Average the three random masks within each image. Report masked accuracy, both losses, and the paired difference in losses for all four patterns, both fills, all three budgets, and each cohort separately. Compare this with the fraction retained correct among images where both models originally predicted the correct breed. The latter has a different denominator.
2. Within one image and image budget, compare the center mask with whichever of the three existing random masks leaves the closest animal fraction visible. Break ties by original repeat index. Accept at most one pair per image and budget, within three percentage points. Choose using annotations alone, share the same selection across fills and models, and report the support for every cell. Compare center and random absolute accuracy for each model and the difference between their two center-minus-random changes. Matching limits differences in animal area. The locations and contents of the surviving patches can still differ.
3. Bootstrap original images within breed, paired across models and conditions, with 10,000 resamples and fixed random seed. Use image-weighted means for both cohorts separately. For the matched subset resample within represented breeds conditional on the selected sample. Report pointwise 95% percentile intervals for exploratory contrasts, show a 12-comparison Bonferroni-adjusted sensitivity interval for the center/random clean-loss differences in each cohort, and suppress subset estimates with fewer than 20 images. No overlap is extrapolated. No new images or trained parameters enter these two checks.

Run `python scripts/final_sensitivity.py` from a checkout with NumPy and pandas. The script reads the original per-model prediction CSVs, checks shared masks, reconstructs correctness from class labels and cross-checks all unadjusted accuracies against the main report.
