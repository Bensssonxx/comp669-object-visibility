# Related work and the scope of the contribution

Checked against primary sources on 2026-10-18. This is a focused source review, not an exhaustive novelty search.

| Source | Relevant established result/design | Relationship to this project |
| --- | --- | --- |
| Naseer et al., *Intriguing Properties of Vision Transformers*, NeurIPS 2021, [paper](https://arxiv.org/html/2105.10497v3), Section 3.1 | Random, salient (foreground) and non-salient (background) PatchDrop. Saliency uses DINO attention; a fraction of saliency mass is not the same as a fraction of pixel area. Hidden RGB pixels are set to zero. | Foreground/background distinction is established prior work. Here, we use human trimap foreground coverage, exact equal image-area budgets, and same-image equal-shape diagnostic pairs on frozen AIMv2/DINOv2. This is an extension, not a novel occlusion principle. |
| Xiao et al., *Noise or Signal: The Role of Image Backgrounds in Object Recognition*, 2020, [paper](https://arxiv.org/abs/2006.09994), [authors' code](https://github.com/MadryLab/backgrounds_challenge) | ImageNet-9 variants disentangle foreground/background signals; backgrounds can support classification and change predictions. | Background effects cannot automatically be dismissed. Pet trimaps let us measure visible background too, but we do not run a background-replacement experiment in the pilot. |
| Fini et al., *Multimodal Autoregressive Pre-training of Large Vision Encoders*, [paper](https://arxiv.org/abs/2411.14402), [official code](https://github.com/apple-aiml-research/ml-aim) | AIMv2 is a multimodally autoregressively pretrained vision-encoder family. Official checkpoints support frozen feature extraction. | AIMv2 is the primary studied encoder. Our frozen mean-patch linear probe is a common diagnostic recipe, not a reproduction of the paper's best ImageNet evaluation. The experiment does not identify the contribution of prefix attention. |
| Oquab et al., *DINOv2: Learning Robust Visual Features without Supervision*, [paper](https://arxiv.org/abs/2304.07193), [official code](https://github.com/facebookresearch/dinov2) | Self-supervised visual features trained using a different data/model pipeline. | DINOv2-L/14 is a reference encoder. Equal input pixels and a shared probe family do not control away pretraining differences. |
| Parkhi et al., *Cats and Dogs*, CVPR 2012, [official dataset](https://www.robots.ox.ac.uk/~vgg/data/pets/) | 37 pet categories with head boxes and pixel trimaps. | The pilot uses the trimap (whole visible animal), not the head box as a whole-object proxy. Split membership and breed labels are validated against official annotation lists. |

The defensible course-project contribution is a reproducible, visibility-aware characterization of these frozen encoders and an audit of what aggregate occlusion curves omit. Whether a pattern is new or practically important depends on observed results and further literature, not simply on the choice of a newer model.

The question is not merely whether occlusion hurts. It is whether equal image-area conditions retain unequal foreground and whether mask-dependent failures persist within same-image pairs whose foreground coverage is closely matched. Even the latter does not equalize discriminative parts, visible texture, background content or position.
