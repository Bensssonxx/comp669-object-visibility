# Reports

- [OCCLUSION_COMPLETION.md](OCCLUSION_COMPLETION.md): the final results. It covers 25/50/75% visibility, the head experiment, moving patches at matched animal area, and the animal versus background swaps on new test photos.
- [EXTENSION_V2.md](EXTENSION_V2.md): the follow-up after the pilot, with 740 new test images, gray and black fill, and the first head experiment.
- [PILOT_REPORT.md](PILOT_REPORT.md): the original smaller experiment.
- [VISIBILITY_PREDICTION.md](VISIBILITY_PREDICTION.md): an exploratory side analysis that predicts which masked images each model gets wrong.

All four are generated from saved predictions by the `report_*.py` and `write_reports.py` scripts. The [code guide](../docs/CODE_GUIDE.md) explains how the stages fit together.
